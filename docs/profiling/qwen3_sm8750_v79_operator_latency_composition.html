口径边界

  • 全图 closure 直接比较官方 Dominant Path HTP0 与 QNN-node direct contribution；当前覆盖约 99.4%，小额差值保留为 unmapped/system。
  • 每个 QNN node 只映射到一个 Qwen3 stage，因此 own critical 可以跨算子相加；E2E envelope、active union 和 work cycles 不能相加为 latency。
  • HMX/HVX/DMA 拆分直接来自 QHAS htp_op_instances 的官方资源标志，其 direct cycles 与 QNN-node contribution 严格守恒；Chrome Trace event direct 仅作为交叉检查。
  • Off-critical overlap 是非关键事件区间与该算子 own-DP 区间的真实交集；它是并行活动量，不额外增加墙钟时间。
  • 量化斜纹是 own HVX critical 的子集，包含 W4 expand/dequant、Convert/CastType、fused requant 和 signed conversion。
