三个 Layer 的局部结构

横轴来自旧 Optrace 的真实时间位置。结构 bar 是 stage 的 start→end envelope，内部可能有空隙；量化/反量化细轨道则绘制合并后的真实活动区间。二者都可能相互重叠，不能按宽度或 work cycles 简单累加。

指标口径

  • Active union：同一行事件区间取并集后的活动时间，比 work cycles 更接近不重复计时的局部占用。
  • Timeline work：事件时长之和，存在并行时会重复计数。
  • Direct critical：QHAS 对 dominant path 的直接归因，不等于删除该阶段后必然获得的加速。
  • Fused requant：显示整个 fused kernel 的区间，目前不能进一步拆出其中仅 requant 指令的净耗时。
