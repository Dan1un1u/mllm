# EXP-0007 — Fair compiler schedule search

The experiment searched compiler P schedules independently for A16 and A8 with
the same candidate set, projection weights, repetitions, and selection rule.
Micrographs showed different optima by dtype and shape: A16 s1 favored P6,
A16 s32 P0, A8 s1 P19, and A8 s32 P17. Full-model evaluation retained the
fastest valid configurations under the common protocol: A16 default and A8 P19.

The scheduling policy was accepted because applying only the A8 optimum would
make the comparison unfair. Schedule changes were checked against the declared
upper-layer numerical behavior.
