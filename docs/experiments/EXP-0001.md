# EXP-0001 — Clean-room W4A8G32 experimental baseline

The New W4A8 line was derived from the archived W4A16 implementation with
signed W4G32 LPBQ weights retained and activations changed to asymmetric U8.
The full conversion, build, device, profiling, manifest, and Optrace pipeline
ran successfully with only informational numerical sanity and no speed gate.

This result established feasibility but was superseded first by native U8
RMSNorm and later by the QAIRT 2.49 selected baseline.
