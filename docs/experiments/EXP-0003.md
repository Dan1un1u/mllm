# EXP-0003 — LPBQ FullyConnected and MatMul MLP lowering

The experiment tested whether expressing the same W4G32 LPBQ projection as
QNN FullyConnected or MatMul selected a faster physical lowering than the
existing Conv2D representation.

On QAIRT 2.47 and 2.49, FullyConnected failed graph finalization at
`q::GenPad`. MatMul passed host layout, structure, and device correctness but
lowered to the same Conv-family W4 expansion and weight-transfer families.
QAIRT 2.49 `up_proj s32` was 9.62% slower than Conv2D and exceeded the 1%
non-regression gate. Work stopped before full-layer and full-model migration.
