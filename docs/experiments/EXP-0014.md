# EXP-0014 — QHPI in-graph U8xS8 HMX feasibility gate

## Hypothesis

QAIRT 2.49 QHPI can execute a custom asymmetric-U8 by signed-S8 matrix product on the V79 integer HMX resource while keeping the operator boundary inside one QNN graph and its internal tensors in TCM.

## Primary physical variable

Replace one fixed-shape native QNN integer MatMul implementation with a QHPI custom U8xS8 HMX implementation; keep shape, integer operands, quantization parameters, output contract, toolchain, hardware, and surrounding graph fixed.

## Hard gate

The micrograph must compile and execute on PJZ110/V79 in one QNN graph; the QHPI descriptor must request HMX and TCM-only internal placement; the custom operator must have zero operator-attributed DDR read/write and no spill/fill or CPU fallback; Optrace must identify its execution; and requantized U8 output must match the independent asymmetric integer reference exactly or within a predeclared one-LSB tolerance. Any failure stops before fused attention.
