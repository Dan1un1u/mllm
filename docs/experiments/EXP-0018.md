# EXP-0018 — Deployment-faithful progressive A8 activation calibration

## Hypothesis

Keeping the deployed W4G32, embedding, and native-U8 RMSNorm quantization active while deriving asymmetric-U8 activation qparams, then optimizing qparams progressively against W4A16 block outputs, will prevent the layer-2 SwiGLU/down-projection outlier from collapsing the residual stream without changing the QNN dtype or operator graph.

## Primary physical variable

Offline asymmetric-U8 activation-qparam derivation policy; weights, model topology, runtime dtypes, QAIRT release, and hardware operators remain fixed.

## Hard gate

Before any formal QNN model generation, the pinned PyTorch fake-quant sanity must stop producing empty or repeated-punctuation degeneration, layer-2 post-block reconstruction versus W4A16 must improve over the selected A8 baseline without moving the first catastrophic cliff earlier, and an audit must show unchanged W4G32/asymmetric-U8/native-U8-RMSNorm runtime contract. If this software gate fails, stop before QNN build and record the failed calibration variant.

## Evidence profile

full-model-performance

## Outcome

Completed on 2026-08-25 with valid evidence and a passing declared local gate.
Project adoption remains pending. This pass has a deliberately narrow meaning:
the candidate removed the original catastrophic all-zero/repeated-punctuation
collapse, improved the layer-2 held-out block reconstruction, and preserved the
deployment contract. It did **not** recover usable full-model quality and is not
a new baseline.

### Software-gate evidence

- Both legacy min-max and deployment-faithful min-max generated token zero / a
  repeated exclamation-mark stream. The selected progressive candidate instead
  generated a non-empty, non-repeated mixed-token stream, satisfying the
  degeneration part of the declared gate.
- Held-out layer-2 post-block median row cosine versus W4A16 is
  `0.8155469298`, improved from approximately `0.756` for the selected A8
  starting point after the same upstream audit. The first catastrophic residual
  cliff was therefore removed rather than moved earlier.
- Error still accumulates after that point: held-out median row cosine is
  `0.7679` at layer 3, `0.7129` at layer 4, `0.6330` at layer 5, and falls to
  roughly `0.34-0.50` through much of the middle/late stack before partially
  recovering near the end. Held-out logit cosine is only `0.0950437561`, and
  candidate/teacher top-1 tokens do not match.
- The formal device sanity suite remains `0/100` and emits non-empty semantic
  gibberish. Thus the calibration experiment repaired catastrophic collapse but
  did not make W4A8 quality usable.
- Runtime-contract audit is unchanged: 957 dynamic A8 activations (901 affine,
  56 symmetric), 28 fixed A8 activations, 197 signed W4G32 LPBQ weights in
  `[-7, 7]`, and 113 U8 RMSNorm weights, all fake-quant paths enabled.

### Performance evidence

The canonical three-round profiling protocol reports:

- Prefill: `775.300 tok/s`, versus selected A8 `783.838 tok/s` (`-1.09%`) and
  W4A16 QAIRT-2.49 comparator `835.963 tok/s` (`-7.26%`).
- Decode: `42.658 tok/s`, versus selected A8 `45.313 tok/s` (`-5.86%`) and
  W4A16 QAIRT-2.49 comparator `46.674 tok/s` (`-8.60%`).

The Optrace critical-path closure is 98.67% for both graphs. Compared with the
selected A8 baseline, captured graph execution changes from 20,254 to 20,490 us
for s1 (`+1.17%`) and from 22,879 to 22,432 us for s32 (`-1.95%`). LPBQ weight
expansion total work and active cycles are effectively unchanged, but more s1
expansion falls on the reported dominant path. The largest positive s1 stage
deltas are MLP up (`+106.6 us`), attention-value (`+98.1 us`), and MLP gate
(`+80.4 us`). This supports a qparam-dependent scheduling/overlap change, not
extra W4 decode work or a graph-contract change. The larger decode E2E delta is
not fully explained by the first captured s1 graph and should not be promoted
to a kernel-level causal claim.

### Conclusion

The hypothesis is supported only at its declared minimum gate: progressive,
deployment-faithful calibration prevents the immediate layer-2 collapse while
keeping the hardware graph intact. Plain per-tensor asymmetric-U8 qparam search
alone is insufficient for quality because direction error continues to
accumulate across later attention and MLP blocks. The result also provides no
speed benefit. It remains a completed candidate with `adoption_status: pending`;
the selected W4A8 baseline and W4A16 comparator roles are unchanged.
