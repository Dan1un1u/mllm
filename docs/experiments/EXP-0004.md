# EXP-0004 — MLP microcontrols

Two mathematically equivalent controls were tested against the native LPBQ
projection.

The explicit U8 encoded-zero bias was byte-exact for six input patterns but its
median timing was 170 versus 167 microseconds, a 1.76% regression, so it did not
pass the 1% non-regression condition. The symmetric two-way gate/up
output-channel split was byte-exact in 12/12 cases; gate projection was slower
in all five rounds and failed the family gate.
